# PokerBank Coach

A SwiftUI poker education app that teaches fundamental poker math and strategy through an interactive Texas Hold'em-style experience.

## Features

* Randomly generates and shuffles a 52-card deck
* Deals player and community cards
* Progresses through pre-flop, flop, turn, river, and showdown
* Provides contextual coaching on poker concepts
* Simulates pot growth throughout each hand
* Uses reusable SwiftUI card and UI components

## Concepts Covered

* Poker combinatorics
* Pocket-pair probabilities
* Flush draws and outs
* Rule of 4 and 2
* Expected Value (EV)
* Implied odds
* Pot equity
* Sklansky Dollars

## Tech Stack

* Swift
* SwiftUI
* Combine
* Xcode

## How to Run

1. Open the project in Xcode.
2. Select an iOS Simulator or connected iPhone.
3. Press `⌘R`.
4. Tap **Advance Phase** to progress through the hand.
5. At showdown, tap **Deal Next Hand** to start a new hand.
